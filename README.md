# 🏦 Bank Loan Analysis Dashboard

## 📌 Project Overview

The Bank Loan Analysis Dashboard is an interactive Power BI project that provides comprehensive insights into loan applications, funded amounts, repayments, loan status, and customer information. The dashboard enables financial institutions to monitor lending performance, evaluate loan quality, and make data-driven business decisions.

---

## 🎯 Business Objectives

- Monitor loan application trends
- Analyze funded and received amounts
- Compare good loans and bad loans
- Evaluate customer loan purposes
- Analyze home ownership distribution
- Monitor loan performance using key KPIs

---

# 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Power Query
- DAX

---

# 📊 Key Performance Indicators

- **Total Loan Applications:** 38.6K
- **Total Funded Amount:** $435.8M
- **Total Amount Received:** $473.1M
- **Average Interest Rate:** 12.0%
- **Average DTI:** 13.3%

# 📈 Dashboard Pages

## 1️⃣ Summary Dashboard

The Summary page provides an overview of loan performance including:

- Good Loan vs Bad Loan Analysis
- Loan Status
- Funded Amount
- Amount Received
- Interest Rate
- Debt-to-Income Ratio (DTI)

---

## 2️⃣ Overview Dashboard

The Overview page analyzes:

- Monthly Loan Applications
- State-wise Loan Distribution
- Loan Term Analysis
- Employee Length
- Loan Purpose
- Home Ownership

---

## 3️⃣ Details Dashboard

The Details page contains:

- Complete Loan Records
- Loan Grade
- Sub Grade
- Interest Rate
- Installment Amount
- Amount Received
- Interactive Filters

# 💡 Key Insights

- Good Loans represent **86.2%** of total applications.
- Bad Loans account for **13.8%** of total applications.
- Debt Consolidation is the most common loan purpose.
- Rent and Mortgage customers contribute the highest number of loan applications.
- Loan applications steadily increased throughout the year.
